BEATSWAP TOOLS

4つ打り・BPM固定の楽曲向け ビート入れ替え／ミュートツール — ブラウザだけで完結

Standard

Beat Swap

1拍単位（4分音符）でビートを入れ替え・スキップできる基本ツールです。BPM自動検出やタップテンポにも対応しています。

  • 1・2・3・4の4パッドをドラッグして入れ替え
  • MUTEでその拍を完全スキップ（無音化ではなく詰める）
  • プレビュー再生／MP3・WAV出力
開く →
Advanced

Beat Swap 16

各拍をさらに4分割し、16分音符単位で細かく入れ替えられる上級版です。行（拍）・列（同じ位置の16分音符）ごとのまとめ操作も可能です。

  • 全16スロットを自由にドラッグして入れ替え
  • 行・列単位のまとめてMUTE／入れ替えボタン
  • プレビュー再生／MP3・WAV出力
開く →
すべての処理はブラウザ内（クライアントサイド）で完結し、音楽ファイルはサーバーにアップロードされません。
対応形式（入力）: MP3 / WAV / OGG / M4A・AAC / FLAC（ブラウザが対応している場合）
対応形式（出力）: MP3 / WAV
